Политика конфиденциальности приложения «Симулятор пробок»

Дата вступления в силу: 31 октября 2026 г.

Разработчик: Матвеев Денис, e-mail: dsmatveev96@gmail.com

Приложение: «Симулятор пробок» (идентификатор пакета com.docke.traffic_sim), распространяется через RuStore.

1. Какие данные собирает приложение

Приложение не собирает, не хранит и не передаёт никакие персональные данные пользователей. Оно не запрашивает разрешений Android, не использует доступ к контактам, геолокации, камере, микрофону, файлам или идентификаторам устройства.

2. Интернет и сторонние сервисы

Приложение работает полностью офлайн и не выполняет сетевых запросов. В приложении нет рекламы, аналитики, встроенных покупок и авторизации. Сторонние SDK для сбора данных не используются.

3. Данные игры

Игровой прогресс хранится только в памяти устройства во время работы приложения и нигде не сохраняется и не передаётся.

4. Дети

Приложение не содержит материалов, не подходящих для детей, и не собирает данные пользователей любого возраста.

5. Изменения политики

При изменении практики обработки данных эта политика будет обновлена, а новая версия опубликована по тому же адресу с новой датой вступления в силу.

6. Контакты

По вопросам, связанным с конфиденциальностью, пишите на dsmatveev96@gmail.com.
